# BroccoliEngine レンダリング・デバッグオーバーレイ 開発ガイド

## 1. 概要

BroccoliEngineの描画システムは、固定仮想解像度、描画コマンドバッファ、World/Screen描画空間、デバッグオーバーレイを共通基盤として提供します。

設計上の目的は次のとおりです。

- ウィンドウサイズに依存しない画面レイアウト
- カメラ変換を受けるゲーム描画とUI描画の分離
- 描画要求の一元的な並べ替えと実行
- Releaseビルドへ影響を残さないデバッグ表示

## 2. 仮想解像度

仮想画面サイズは `EngineDefine.h` で固定されています。

```cpp
constexpr int VirtualWidth = 1920;
constexpr int VirtualHeight = 1080;
```

ゲーム描画は1920×1080の仮想スクリーンを基準に構築します。実ウィンドウの解像度が異なる場合、最終表示時にアスペクト比を維持して拡大・縮小します。

### 2.1 レターボックス

ウィンドウのアスペクト比が16:9でない場合、余った領域には黒帯が入ります。

- 横長ウィンドウ：左右に黒帯
- 縦長ウィンドウ：上下に黒帯
- 16:9ウィンドウ：原則として黒帯なし

このため、ゲームロジックやUIは原則として1920×1080基準で配置してください。

### 2.2 開発上の指針

- UI座標は仮想解像度基準で指定する
- OSウィンドウの実ピクセル値を直接レイアウトへ使用しない
- マウス入力は必要に応じて仮想スクリーン座標へ変換する
- 画面端UIは `0..1920`、`0..1080` の範囲を基準に設計する

## 3. RenderSystemのコマンドバッファ

描画側は即時にGPU描画せず、`RenderSystem`へコマンドを送信します。

主なAPIは次のとおりです。

```cpp
RenderSystem::GetInstance().SubmitGraph(...);
RenderSystem::GetInstance().SubmitRectGraph(...);
RenderSystem::GetInstance().SubmitBox(...);
RenderSystem::GetInstance().SubmitCircle(...);
RenderSystem::GetInstance().SubmitLine(...);
RenderSystem::GetInstance().SubmitText(...);
```

各コマンドは `RenderCommand` として蓄積されます。

```cpp
struct RenderCommon {
  int priority = 0;
  int alpha = 255;
  RenderSpace space = RenderSpace::World;
};
```

描画時にはPriority、Alpha、RenderSpace、各図形データがまとめて処理されます。

## 4. RenderSpace

```cpp
enum class RenderSpace {
  World,
  Screen
};
```

### 4.1 `RenderSpace::World`

ワールド座標として扱われ、カメラの影響を受けます。

- カメラ位置
- カメラズーム/FOV
- カメラ回転
- ビューカリング

ゲーム内Actor、背景、エフェクト、ワールド内デバッグ図形に使用します。

```cpp
RenderSystem::GetInstance().SubmitCircle(
    GetActorLocation(),
    64.0f,
    FColor::White,
    false,
    RenderSpace::World,
    10
);
```

### 4.2 `RenderSpace::Screen`

仮想スクリーンへ固定され、カメラ変換を受けません。

HUD、メニュー、照準、画面固定テキストなどに使用します。

```cpp
RenderSystem::GetInstance().SubmitText(
    FVector2D{40.0f, 40.0f},
    "Objective: Open the door",
    FontHandle,
    FColor::White,
    RenderSpace::Screen,
    100
);
```

### 4.3 座標変換API

```cpp
FVector2D Screen = RenderSystem::GetInstance().WorldToScreen(WorldPosition);
FVector2D World = RenderSystem::GetInstance().ScreenToWorld(ScreenPosition);
```

Actor位置へScreen Space UIを重ねる場合や、マウス座標からワールド位置を求める場合に使用します。

## 5. Priority

Priorityは描画順を決定する値です。値が大きいほど後段に描画される設計として統一してください。

推奨例：

| 用途 | Priority例 |
|---|---:|
| 背景 | 0 |
| ゲームActor | 10 |
| エフェクト | 30 |
| Worldデバッグ | 80 |
| HUD/UI | 100 |
| モーダルUI | 200 |

プロジェクト内で範囲を規約化すると、描画順の競合を防げます。

## 6. コンポーネントからの描画設定

Sprite系Componentでは、描画PriorityとRenderSpaceをまとめて設定できます。

```cpp
BodySprite->SetRenderSettings(10, RenderSpace::World);
```

UI用Componentでは `RenderSpace::Screen` を指定します。

## 7. デバッグオーバーレイ

### 7.1 画面固定ログ

```cpp
DRAW_SCREEN_LOG(
    "NetworkStatus",
    0.1f,
    "Ping: {} ms",
    PingMilliseconds
);
```

同じKeyを継続して送信すると、既存表示を更新する用途に利用できます。

### 7.2 World追従ログ

```cpp
DRAW_WORLD_LOG(
    "HealthKey",
    0.1f,
    this,
    "HP: {:.0f}",
    CurrentHealth
);
```

Actorポインタを渡した場合、表示位置はActorのワールド位置へ追従します。

固定ワールド座標を渡す形式も利用できます。

```cpp
DRAW_WORLD_LOG(
    "SpawnPoint",
    1.0f,
    FVector2D{500.0f, 300.0f},
    "Spawn Here"
);
```

### 7.3 表示時間

第2引数は表示維持時間です。

- 毎フレーム更新する値：`0.1f` 程度
- イベント通知：`1.0f` 以上
- 長時間表示：更新頻度と重複Keyを考慮する

## 8. Releaseビルド時の動作

`_RELEASE` が定義されたビルドでは、デバッグ描画マクロは空処理へ展開されます。

```cpp
#define DRAW_WORLD_LOG(...) ((void)0)
```

そのため、Releaseビルドでは次の処理が発生しません。

- `std::format` の実行
- DebugOverlayManagerへの登録
- テキスト描画コマンド生成
- Actor追跡用データ保持

ただし、マクロ引数に副作用を含めないでください。

```cpp
// 非推奨: ReleaseでIncrementCounter()が呼ばれなくなる
DRAW_SCREEN_LOG("Counter", 1.0f, "{}", IncrementCounter());
```

先に値を計算し、ログは観測用途だけにします。

## 9. ビューカリング

World Spaceコマンドは、カメラ範囲外の場合に描画対象から除外できます。

```cpp
RenderSystem& Renderer = RenderSystem::GetInstance();
Renderer.SetViewCullingEnabled(true);
Renderer.SetViewCullingMargin(128.0f);
```

統計確認用APIも用意されています。

```cpp
std::size_t Submitted = Renderer.GetLastSubmittedCommandCount();
std::size_t Culled = Renderer.GetLastCulledCommandCount();
```

大量のWorld描画を追加した際の負荷確認に利用します。

## 10. 実装例

```cpp
void AEnemyActor::Draw() {
  AActor::Draw();

  RenderSystem& Renderer = RenderSystem::GetInstance();

  Renderer.SubmitCircle(
      GetActorLocation(),
      DetectionRadius,
      FColor::White,
      false,
      RenderSpace::World,
      20
  );

  DRAW_WORLD_LOG(
      "EnemyState",
      0.1f,
      this,
      "State: {} / HP: {:.0f}",
      StateName,
      CurrentHealth
  );
}
```

## 11. 注意事項

- World座標とScreen座標を混在させないでください。
- UIは実ウィンドウサイズではなく仮想解像度を基準にします。
- 毎フレーム異なるログKeyを生成しないでください。
- Debugログの引数にゲーム状態を変更する処理を入れないでください。
- 大量の図形描画ではビューカリングとPriority設計を確認してください。
- Actor破棄後も参照される可能性がある永続デバッグ情報は、寿命管理に注意してください。
